# 雙向極光防禦策略 (Aurora Dual-Engine Strategy)

> 富途牛牛「策略卡片」畫布藍圖 — 趨勢跟隨 (Trend Following) + 波動率克制 (Volatility Control) 全自動雙向切換
>
> 設計目標：長線穩定營利、極致壓低回撤 (Max Drawdown < 8%)、**無需人為參與**、**異常自癒**。

---

## 一、策略核心思想

要將回撤降到最低，核心從來唔係「開倉指標有幾準」，而係：

1. **資金管理 (Position Sizing)** — 用 ATR 動態配倉，將每筆交易嘅潛在虧損死死鎖喺一個固定金額之內。
2. **動態風險截斷 (Dynamic Risk Cut-off)** — 移動追蹤止損 + 每日資產熔斷，唔畀單筆同單日虧損失控。

開倉只用「趨勢過濾 + 突破確認」做方向盤；真正壓回撤嘅靈魂喺配倉同止損。

---

## 二、全局變量（策略嘅「記憶盒」）

開始拉卡片線之前，必須喺右側「變量管理器」建立以下五個全局變量：

| 變量名稱 | 程式代號 | 初始值 | 作用與功能說明 |
| --- | --- | --- | --- |
| 當前持倉狀態 | `position_state` | `0` | `0` = 空倉；`1` = 持有好倉 (Long)；`-1` = 持有淡倉 (Short)。 |
| 動態最高價 | `dynamic_high` | `0` | 好倉移動止損嘅追蹤高位。 |
| 動態最低價 | `dynamic_low` | `99999` | 淡倉移動止損嘅追蹤低位。 |
| 今日回撤警戒線 | `daily_dd_line` | `0` | 開市鎖定當日熔斷價位，防止單日資產大幅回吐。 |
| 每筆風險金額 | `risk_per_trade` | `1000` | 每筆交易願意承受嘅最大虧損（預設 $1000 港幣）。 |

> ⚠️ 重置規範：任何一次「平倉」動作完成後，必須將 `position_state` 重置為 `0`、`dynamic_high` 重置為 `0`、`dynamic_low` 重置為 `99999`，下一筆交易先唔會用到舊倉位嘅殘留追蹤值。

---

## 三、四大獨立卡片路徑（高速公路佈局）

四條路徑各自獨立觸發，透過上面五個全局變量共享狀態，互不阻塞。

### 路徑一：開市初始化與每日對賬（每日 09:15 觸發）

```
[定時觸發 09:15]
      │
      ▼
[賬戶數據：讀取資產總值 equity]
      │
      ▼
[賦值運算] daily_dd_line = equity × 0.98          ← 單日最大容忍虧損 2%
      │
      ├──[改進#2] 如果 今日 == 星期五 AND 現時 >= 15:50
      │            └──> [強制將所有持倉手數砍 50%]   ← 防週末跳空黑天鵝
      │
      ▼
[盤中監控] 若 即時資產總值 < daily_dd_line
            └──> 觸發全日熔斷：market_close_all() → position_state = 0 → 全日罷工
```

**自癒重點：** 一旦觸發熔斷，當日唔再開任何新倉，直到下一個交易日 09:15 重新對賬。

---

### 路徑二：多空信號開倉與自動切換引擎（盤中每根 K 線收盤觸發）

策略嘅「方向盤」：`EMA 趨勢過濾` 配合 `布林線 (Bollinger Bands) 突破`。

```
[每根 K 線收盤]
      │
      ▼
[K線收盤價 > 布林上軌  AND  EMA50 > EMA200] ── 是 ──> 檢查 position_state == -1 ?
      │                                                  ├─ 是（持淡倉）─> 【先平淡倉 → 確認 0 倉 → 開好倉】
      │                                                  └─ 否（空倉）──> 【直接開好倉】
      │                                                                          │
      否                                                                         ▼ position_state = 1
      ▼
[K線收盤價 < 布林下軌  AND  EMA50 < EMA200] ── 是 ──> 檢查 position_state == 1 ?
                                                         ├─ 是（持好倉）─> 【先平好倉 → 確認 0 倉 → 開淡倉】
                                                         └─ 否（空倉）──> 【直接開淡倉】
                                                                                 │
                                                                                 ▼ position_state = -1
```

**自動切換 (Reversal) 三步走閉環（防鎖倉陷阱，見第五節）：**

1. 調用「平倉卡片」清空當前反向持倉（市價全平）。
2. 讀取賬戶 → 確認持倉數量 == 0。
3. 等 **200 毫秒** 訂單隊列清爽後，再調用「高級下單卡片」開立反向新倉，並更新 `position_state`。

---

### 路徑三：最少化回撤核心 — ATR 風險配倉引擎（開倉當刻執行）

> 壓低回撤嘅靈魂：**絕不盲目買固定手數。**

```
[開倉觸發]
      │
      ▼
[讀取當前 ATR 指標數值]
      │
      ▼
[算式卡片]  下單股數 = risk_per_trade ÷ (ATR × 2)
      │
      ▼
[取整 → 下單]
```

**公式：**

```
下單股數 = 每筆風險金額 / (ATR × 2)
```

**作用：** 波動劇烈 (ATR ↑) → 股數自動變少；市場平靜 (ATR ↓) → 股數自動變多。
無論市場點震，每筆交易嘅潛在虧損都鎖死喺 `risk_per_trade`（$1000）內，從源頭扼殺大回撤。

---

### 路徑四：雙向動態追蹤止損防線（盤中 Tick 級刷新）

> 採用 **改進#1 非對稱多空止損系數**：升得慢、跌得急，所以淡倉止損收得更緊。

**好倉防線（`position_state == 1`）— 系數 2.0 × ATR：**

```
若 現價 > dynamic_high            ──> dynamic_high = 現價         （更新高位）
止損：現價 < dynamic_high - (2.0 × ATR)  ──> 市價平倉 → 變量重置
```

**淡倉防線（`position_state == -1`）— 系數 1.5 × ATR（更敏感）：**

```
若 現價 < dynamic_low             ──> dynamic_low = 現價          （越低越賺，更新低位）
止損：現價 > dynamic_low + (1.5 × ATR)   ──> 市價平倉（買入補回）→ 變量重置
```

## 四、改進建議（已併入上面藍圖）

1. **非對稱多空止損系數** — 好倉 `2.0 × ATR`，淡倉收緊至 `1.5 × ATR`，防空頭利潤被瞬間回吐。（已落入路徑四）
2. **週五尾盤強制減倉** — 星期五 ≥ 15:50 強制砍 50% 持倉，避過週末地緣黑天鵝週一跳空。（已落入路徑一）
3. **三方平台交叉認證** — 富途卡片 / TradingView Pine Script / QuantConnect Python 跑同一段歷史數據，三邊 `Profit Factor > 1.5` 且 `Max Drawdown < 8%` 先可投入實盤。（見第六節）

## 五、提醒：多空反向切換嘅「鎖倉陷阱」

**混淆點：** 以為手上有好倉時，直接發一張「賣出」訂單就可以開淡倉。

**真實風險：** 喺某些期貨／股票賬戶，持好倉時直接「賣出」會被默認為**平倉**，唔會幫你建立反向淡倉；或變成**雙向鎖倉**（同時持多單同空單），白白浪費保證金。

**自癒規範（硬性規則）：**

```
先調用平倉卡片清空當前持倉
        → 讀取賬戶確認持倉 == 0
              → 再調用高級下單卡片開立反向新倉
```

「買入 / 賣出」係訂單方向；「開倉 / 平倉」係倉位意圖 — 兩者必須分開處理，唔可以靠單一訂單同時完成反向切換。
